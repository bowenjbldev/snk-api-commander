SNAKECLOUD CMS Hi-fi screens — Carbon v11 Theme
Working notes — assumptions & system
  • System. Carbon v11 vocabulary, recreated by hand: IBM Plex Sans / Plex Mono, productive type scale, sharp corners everywhere except full-round tags, 1px borders on layer boundaries, IBM Blue 60 reserved for the single primary action per screen. Color appears only as status semantics (green / amber / red) and the Carbon categorical palette in charts.
  • Themes. Gray 100 is the default; the control above flips the whole gallery to White/G10. The UI Shell header intentionally stays g100 in both themes, as on IBM Cloud.
  • Data. One coherent dataset across every frame — 8 clients, 15 deployments. The story: acme-shop was auto-suspended over overdue invoice INV-2026-0139; kestrel-track is in grace with 13h 42m left; helios-meter is 124% over its requests_day quota. Every screen reflects these same facts.
  • Static frames. Per your answer this is a flat gallery — drawers, modals and menus are shown as captured states; numbers are right-aligned mono, relative dates carry dotted underlines to indicate hover tooltips. Tell me which flows to wire into a clickable build next.
  • Variations. Section 10 explores 3 KPI-card treatments, 3 status-tag treatments and 3 detail-tab treatments to mix and match before I lock the system in.
